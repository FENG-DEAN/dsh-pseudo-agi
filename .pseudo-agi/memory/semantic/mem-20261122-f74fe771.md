pseudo-agi 记忆层现在有显式取代机制（supersedes）：memory_candidate 接受 supersedes: [id...]，提交时给被取代的记录写入 front-matter 字段 supersededBy，文件保留在磁盘上作为历史，但 scan() 默认过滤掉它们——召回、每步注入、working.md 摘要都看不见。

设计原则：谁取代谁是语义判断，归模型；装置只做执行（写 supersededBy）与过滤（scan 默认跳过）。不做自动裁决的理由：按时间序或置信度自动挑一条，在"两边都错"时错得更隐蔽；显式取代可回退，改一行 front-matter 即恢复。

实现要点：MemoryRecord 增加 supersededBy / supersedes；scan(layers, { includeSuperseded }) 默认 false；writeRecord 写完新记录后调 markSuperseded；commitCandidate 把候选的 supersedes 带到提交阶段而不是在 staging 时执行（不能凭未提交的主张退掉旧记忆）；markSuperseded 经 scan(includeSuperseded: true) 找目标文件并原子重写。

仍缺：时间序/置信度自动裁决；面板的 parseRecord 未读 supersededBy，历史记录会显示成普通记录。
