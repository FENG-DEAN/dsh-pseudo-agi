pseudo-agi 记忆层新增冲突检测：memory_recall 的返回带 conflicts 字段，对命中记录两两比对，共享至少一个 tag 且标题重叠 ≥2 个词即报出这对 id 与共享标签；renderRecall 附 ⚠ 提示并建议用 supersedes 修正。

设计取舍：只报告，不过滤、不重排、不自动挑。理由是"哪条仍然成立"是语义判断，只有读者能做；自动裁决（按时间序或置信度挑一条）在"两边都错"时错得更隐蔽。装置能做的、模型做不到的是——扫描全部命中并两两比对，模型不会主动做这件事。

实现：store.ts 的 RecallConflict 类型 + conflictsOf(hits) 辅助函数；recall 三条返回路径（空查询/空库/正常）都带 conflicts: []；tools.ts 的 output schema 增加 conflicts，且因类型 readonly 不兼容，返回时要 map 成可变数组。测试：smoke 35→37，正例（同标签+标题重叠→报 1 对）与反例（标签不相交→0 对）。

仍未做：时间序自动裁决、置信度衰减。
