判断权归模型，装置只做模型自己做不到的四件事：改自己的上下文、跨步持久化、强制边界、留下可审计轨迹。

- **意识 = 模型**：这一步做什么、记什么、调哪个工具，全部由模型判断。任何关键词路由插件都是降级，已删除。
- **scaffold（脚手架）**：每轮首步经 `agent/pre-step` 注入一条纪律（来源、没找到就说没找到、写前说明意图、未取证要标注），并发 `pseudo-agi/scaffold-step` 事件。不读用户文本、不看工具列表、`inject: []`。
- **memory（记忆）**：Markdown 为真源，`.pseudo-agi/memory/<layer>/mem-*.md`；候选 → 证据校验 → 提交；每步按 token 预算注入；召回必须带 evidence，无命中返回 `found:false` + note。
- **tools（手脚）**：`kb_search`/`kb_read`/`controlled_write`；路径边界由 `ctx.tools.guard()` 单调否决（越界、.git、可执行扩展名、尺寸），审批不当人工闸门。
- **governance（治理）**：只读观察 step/scaffold/tool/turn/memory 事件，写 JSONL 与内存指标，提供 `governance_report`；从不干预决策。
