2026-11-22 修复 pseudo-agi-panel 的路由无鉴权问题。

做法：panel 在 Host 侧自己验证 Host Connection 的浏览器会话 cookie，而不是改 DSH 或复制其内部类 BrowserAuth（该类未作为服务暴露）。用 ctx.get('credentials').readRecord('client-connection/browser-session') 取 secret，用 createHmac + timingSafeEqual 验签名，并校验 cookie 绑定的 authority 等于请求 host、issuedAt <= now < expiresAt。拿不到 secret 时放行并只 warn 一次，保证最小宿主与单测环境不被锁死。

测试：scripts/panel-test.mjs 从 9 例扩到 14 例并全部通过，新增覆盖 有效 cookie→200、无 cookie→401、伪造签名→401、过期→401、authority 不符→401；smoke 25/25、profile-check 12/12 未回归。

限制：改的是 link: 包源码，宿主进程仍持有旧模块，真机行为必须重启 desktop profile 后才能确认——届时用无 cookie 的请求应得 401，浏览器面板应仍能正常加载（同源 fetch 默认携带 cookie）。
