新会话开工第一件事：`kb_read({ path: "AGI_STATE.md" })`，读目标 / 已完成 / 下一步 / 阻塞四节，再用 `memory_recall` 取事实记忆。二者合起来才是完整的"正在做什么 + 知道什么"。

收工流程：更新 `AGI_STATE.md`（追加验证记录、改写下一步），然后 `git add -A && git commit`，把这一轮的记忆与文档变更落成可回滚的轨迹。

不做的事：不依赖关键词控制器替我决定先检索还是先动手；不把临时结论写成事实记忆（先 candidate，确认后再 commit）。
