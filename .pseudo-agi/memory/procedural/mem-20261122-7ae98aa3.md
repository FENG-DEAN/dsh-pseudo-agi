Web 前端显示时间戳时，不要用 String(iso).slice() 直接截取日期或时间部分——那等于渲染 UTC。在 UTC+8 下事件时间会差 8 小时（16:58 显示成 08:58），日期在 UTC 23:00 之后会错到前一天。

正确做法：new Date(value) 后用 toLocaleDateString() / toLocaleTimeString(undefined, { hour12: false })，按浏览器时区渲染；对无效时间戳先检查 Number.isNaN(at.getTime()) 再决定回退（显示原始片段或空），不要抛错。

实例：pseudo-agi-panel 的 client.js 原用 String(record.at).slice(11,19) 与 slice(0,10)，用户截图看出 08:58 vs 本地 16:5x；改成 localTime() 后用户确认正确。

附带教训：手改 JS 文件后先跑 node --check，本次改这一行时漏了一个收尾括号，语法检查当场报 missing ) after argument list，比在浏览器里看白屏快得多。
